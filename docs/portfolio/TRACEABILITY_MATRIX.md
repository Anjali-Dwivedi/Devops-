## Evidence types

- `impl` — code / IaC / pipeline in repo
- `test` — automated test result
- `demo` — scripted success/failure demonstration
- `diagram` — architecture or flow diagram
- `doc` — design/runbook/interview Q&A only
- `deploy` — verified cloud deployment (approval-gated)

## Verification statuses

- `pending` — not yet built
- `implemented` — code present, not fully verified
- `verified` — checks run successfully
- `doc-only` — intentionally documentation-only
- `blocked` — external prerequisite
